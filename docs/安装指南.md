# 安装指南（零基础版）

不需要懂代码，不需要装任何软件。跟着做，5 分钟搞定。

> 适用：macOS / Windows。Linux 用户看 [README](../README.md) 里的命令行方式。

---

## 开始前，确认两件事

**1. 你的 IGV 在哪？**

- Mac：打开「访达 → 应用程序」，应该能看到 `IGV_2.19.1.app` 这样的图标
- Windows：开始菜单里搜 IGV 能打开

**2. 你的 IGV 是什么版本？**

打开 IGV，看窗口标题栏，或者菜单 `Help → About IGV`，会显示类似 `2.19.1` 的数字。

记下来，下一步要用。不确定也没关系，下载 2.19 的版本通常都能用。

---

## 第一步：下载

打开这个地址：

**https://github.com/poplarity/igv-lingo/releases/latest**

在页面最下面的 **Assets** 里，找到名字像这样的文件：

```
igv-lingo-zh_CN-2.19.1.zip
```

点它下载。（数字对应你的 IGV 版本；没有完全一致的，就挑最接近的。）

---

## 第二步：解压

下载完成后，双击 zip 文件。

- Mac：会解压出一个文件夹 `igv-lingo-zh_CN-2.19.1`
- Windows：右键 zip →「全部解压缩」

打开这个文件夹，里面应该有这样几个文件：

```
install-mac.command        ← Mac 双击这个
install-windows.bat        ← Windows 双击这个
使用说明.txt
igv-lingo-agent.jar
deny_by_class.tsv
locales/
```

---

## 第三步：双击安装

### Mac

双击 `install-mac.command`。

会弹出一个终端窗口，自动跑几行字。最后看到：

```
======================================
  安装完成 🎉
======================================
```

**如果提示"无法打开，因为来自身份不明的开发者"：**

1. 关掉提示
2. **右键**（或按住 Control 点）`install-mac.command`
3. 选「打开」
4. 在弹窗里再点一次「打开」

只需要第一次这样做，以后再双击就正常了。

### Windows

双击 `install-windows.bat`。

**如果弹出"Windows 已保护你的电脑"：**

1. 点「更多信息」
2. 点「仍要运行」

看到"安装完成"的提示框，点确定。

---

## 第四步：重启 IGV（这一步最容易漏）

安装只是把文件放好了，**IGV 需要重新启动才会读它们**。

- Mac：点一下 IGV 窗口，按 **Command + Q** 完全退出
  （只点左上角红叉是关窗口，不算退出）
- Windows：菜单 `File → Exit`

然后重新打开 IGV。

---

## 第五步：检查

看屏幕最上面的菜单栏。中文的话应该是：

```
文件   基因组   视图   轨道   区域   工具   帮助
```

## 没生效？对照这张表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 菜单还是英文 | IGV 没有完全退出 | Mac 按 `Command+Q`；Windows 用 `File → Exit`，然后重开 |
| 双击脚本没反应 | 被系统拦了 | Mac 右键 → 打开；Windows 右键 → 以管理员身份运行 |
| 提示"找不到 IGV" | IGV 没在「应用程序」里 | 把 IGV 拖进「应用程序」文件夹，再双击一次脚本 |
| 只有部分中文 | 正常 | 词表还没翻完，看 [进度](https://github.com/poplarity/igv-lingo#效果) |
| 想确认装没装 | — | 看日志文件：Mac `~/.igv/lingo/igv-lingo.log`；Windows `C:\Users\你的用户名\.igv\lingo\igv-lingo.log` |

日志里出现这行就说明成功加载了：

```
[igv-lingo] 语言 zh_CN，词条 360，禁译规则 1031
```

还搞不定，把日志内容贴到 [Issues](https://github.com/poplarity/igv-lingo/issues)。

---

## 不想要了，怎么恢复英文

在同一个文件夹里：

- Mac：双击 `uninstall-mac.command`
- Windows：双击 `uninstall-windows.bat`

然后重启 IGV，就回到英文了。

想彻底清干净，再删掉这个文件夹：

- Mac：`~/.igv/lingo`
- Windows：`C:\Users\你的用户名\.igv\lingo`

## 常见疑问

**会不会把我的 IGV 弄坏？**
不会。IGV 安装目录里的文件一个都没动。汉化只是在你自己的用户目录放了一份词表，
并在 `~/.igv/java_arguments` 里加了一行（加之前自动备份）。删掉就恢复原样。

**需要装 Java 吗？**
不需要。IGV 自带。

**为什么默认是中文？**
装好就是中文，不需要设置。只有你系统语言既不是中文、又装了多个语言包时，才会按系统语言选。

**能用在 Windows 的 IGV 上吗？**
可以，双击 `install-windows.bat`。不过作者只在 Mac 上实测过，Windows 有问题请提 Issue。

**会影响 IGV 的速度吗？**
不会。只在 IGV 启动、加载界面类的时候改一次字符串，之后没有任何开销。
